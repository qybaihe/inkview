# Ink Common Icon Sheet Prompts

## Shared Base Prompt

Use case: stylized-concept icon library.
Asset type: general-purpose Chinese ink-wash icon sprite sheet.
Primary request: Create 12 separate simple ink-wash icons on one pure green chroma-key sheet.
Style: elegant modern Chinese ink-wash icon style, sumi-e brush strokes, soft grey ink gradients inside each object, visible dry-brush texture, off-white rice-paper fill inside the icon shapes, restrained accent colors from cinnabar red, indigo blue, jade green, warm ochre, and muted gold. Each icon should feel like a compact app icon sticker, not a realistic painting.
Simplicity: broad everyday UI meanings, recognizable at 128px, one main object per cell, no tiny details.
Layout: exactly 4 columns by 3 rows, equal spacing, one complete icon centered in each cell, generous padding, no overlaps, no cropping.
Background: perfectly flat solid #00ff00 chroma-key background. The background must be one uniform color with no shadows, gradients, texture, reflections, floor plane, paper texture, or lighting variation. Do not use #00ff00 anywhere in any icon.
Output constraints: no labels, no readable text, no watermarks, no realistic cast shadows, no 3D rendering, no photorealism.

For expansion sheets 09 and later, use 16 icons per sheet with exactly 4 columns by 4 rows. Keep the same icon scale and generous padding.
