# InkView Instructions for Claude Code

Use InkView when the user asks to transform a website, web app, landing page, dashboard, or UI prototype into a refined modern Chinese ink-wash / guofeng style.

## Workflow

1. Inspect the website's structure and current styling.
2. Preserve information architecture, copy, conversion goals, accessibility, and interactions.
3. Apply the InkView design system from `docs/design-system.md`.
4. Select semantic icons from `assets/ink-common-icons/wiki/icon-wiki.tsv`.
5. Copy selected PNG icons into the target project's own asset directory before referencing them.
6. Verify responsive layout, contrast, and icon paths.

## Style

- Warm rice-paper backgrounds.
- Dry-brush dividers and borders.
- Strong ink text and subtle grey ink wash.
- Restrained cinnabar, jade, indigo, and ochre accents.
- Modern readable typography for functional UI.

## Avoid

- Heavy red-gold palace aesthetics.
- Fantasy/xianxia game UI.
- Low contrast aged paper.
- Decorative clutter over functional UI.
- Calligraphy fonts for forms, tables, navigation, or buttons.
