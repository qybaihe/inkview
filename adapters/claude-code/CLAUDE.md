# InkView Instructions for Claude Code

Use these instructions when the user asks to apply InkView, water-ink, sumi-e, guofeng, Chinese classical, xuan paper, or ink brush styling to a website.

## Workflow

1. Inspect the website's structure and current styling.
2. Preserve information architecture, copy, conversion goals, and interactions.
3. Apply a modern Chinese ink-wash visual system:
   - warm rice-paper backgrounds
   - dry-brush dividers and borders
   - strong ink text
   - subtle grey ink wash
   - restrained cinnabar, jade, indigo, and ochre accents
4. Use semantic icons from InkView's `assets/ink-common-icons/wiki/icon-wiki.tsv`.
5. Copy selected PNG icons into the target project's own asset directory before referencing them.
6. Verify mobile and desktop layouts, contrast, and icon paths.

## Avoid

- Heavy red-gold palace aesthetics.
- Fantasy/xianxia game UI.
- Low contrast aged paper.
- Decorative clutter over functional UI.
- Calligraphy fonts for forms, tables, navigation, or buttons.
