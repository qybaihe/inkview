# Website Patterns

## Landing Page

- Use a paper-toned full-page background and an unframed hero composition.
- Put a pale ink circle, brush landscape, or selected icon cluster behind the main subject with low opacity.
- Use cinnabar for one primary action or seal-like status mark.
- Let the next section peek into the first viewport.

## Dashboard

- Keep dense workflows intact.
- Use ink tokens for surfaces, borders, focus rings, and section headers.
- Use icons sparingly for top-level modules, empty states, or nav categories.
- Do not convert tables into decorative cards if the table is the core workflow.

## Portfolio or Culture Site

- Use more vertical rhythm, paper layers, and brush dividers.
- Pair icon accents with real images or artwork when available.
- Use larger headings, but keep body typography modern.

## Forms and Checkout

- Prioritize clarity and trust.
- Use paper panels, strong input borders, subtle focus rings, and small ink icons for section labels.
- Avoid decorative textures inside input fields.

## Empty States

- Choose one strong icon from the bundled library.
- Use a short heading, one sentence, and one clear action.
- Add a pale ink circle or light paper card behind the icon only if the page has room.
