# Ink Common Component Sheet Prompts

## Shared Base Prompt

Use case: transparent UI component material library.
Asset type: modern Chinese ink-wash website component assets.
Primary request: Create 4 separate ink-wash UI component materials on one pure green chroma-key sheet.
Style: refined modern Chinese ink-wash product UI, rice-paper surfaces, dry-brush black ink outlines, soft grey ink wash, subtle xuan paper fill inside components, restrained cinnabar red, jade green, indigo blue, warm ochre, and muted gold accents. Components should feel usable in modern websites, not antique palace decoration.
Component rule: these are transparent UI materials to overlay or merge with real HTML/React components. They should have no readable text; use only abstract short lines, dots, placeholders, and simple UI marks.
Layout: exactly 2 columns by 2 rows, equal spacing, one complete component centered per cell, generous padding, no overlaps, no cropping. Components may be horizontal, vertical, or card-shaped, but each must stay fully inside its cell.
Background: perfectly flat solid #00ff00 chroma-key background. The background must be one uniform color with no shadows, gradients, texture, reflections, floor plane, paper texture, or lighting variation. Do not use #00ff00 anywhere inside any component.
Output constraints: no readable text, no watermarks, no realistic cast shadows, no 3D rendering, no photorealism, no full webpage screenshot.
