# InkView Agent Prompt

Use InkView to transform this website into a refined modern Chinese ink-wash design.

Preserve the website's information architecture, content priority, conversion goals, and core interactions. Copy selected icons and components into the target project's own asset directory before referencing them. Avoid heavy red-gold palettes, fantasy/xianxia imagery, fake old-paper grime, low contrast, and decorative elements that interfere with scanning, forms, tables, or calls to action.
