# InkView Agent 提示词

使用 InkView 将这个网站改造成精致的现代中式水墨风。

保留网站的信息架构、内容优先级、转化目标和核心交互。用宣纸界面、飞白墨线、克制的朱砂/青玉/靛蓝/赭石点睛、舒展留白、清晰排版、语义匹配的本地图标，以及适合真实文字的 text-safe 组件外壳来重塑视觉系统。

引用图标或组件前，先把选中的 PNG 复制到目标项目自己的资源目录。卡片、表单、列表、表格、按钮、提醒和移动端真实文案区域优先使用 `assets/ink-text-safe-components/`。避免满屏红金、页游仙侠、脏旧纸纹、低对比，以及会干扰阅读、表单、表格或行动按钮的纯装饰元素。
